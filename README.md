# bible-study-dev

Tools and notes for biblical Hebrew & Greek parsing, plus software dev experiments  
(React Native/Flutter, Azure, APIs). Structured data (JSON/CSV), study aids, and small utilities.

## Contents

- `GreekApp02_ScriptureSelect_v40.html` – Scripture selection UI for a Greek study app.
- `notes/` – Study notes (Hebrew/Greek parsing, exegesis).
- `data/` – Vocab lists and structured data (JSON/CSV).
- `apps/` – Small app prototypes and experiments.

## How to use

- Open `*.html` files directly in a browser.
- Check `notes/` and `data/` for study materials.
